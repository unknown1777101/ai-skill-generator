# React Modal Generator

## 🎯 Purpose & Scope
Scaffolds modular accessible React dialog/modal components using TailwindCSS.

## 🛑 Strict Guardrails
- **DO NOT** import third-party modal libraries outside Tailwind.
- **DO NOT** modify global styles directly.

## 📋 Execution Workflow
1. Inspect `src/components/` directory structure.
2. Write component to `src/components/Modal.tsx`.
3. Verify render cleanly.

## 🔍 Verification Checklist
- [ ] TypeScript types explicit.
- [ ] Passed validation.
